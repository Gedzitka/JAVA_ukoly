# Sada3 - Dokumentace

Účel:
- Ukázkové třídy pro práci s komplexními čísly.

Obsah složky `src`:
- `KomplexniCislo.java` - třída reprezentující komplexní číslo (operace, výpis).
- `Main.java` - jednoduchý spouštěč pro demonstraci funkcí `KomplexniCislo`.

Jak zkompilovat a spustit:
1. Otevřete terminál v kořeni složky `Sada3`.
2. Zkompilujte: `javac -d out src/*.java`
3. Spusťte: `java -cp out Main`

Poznámky:
- Součástí jsou jednoduché příklady použití v `Main.java`.
